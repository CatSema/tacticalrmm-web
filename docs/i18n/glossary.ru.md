# Глоссарий терминов (RU)

Источник: `docs/i18n/translation-rules.ru.md`.

| English   | Русский            | Примечание                             |
| --------- | ------------------ | -------------------------------------- |
| Agent     | Агент              | Сущность в системе                     |
| Client    | Клиент             | Организация/заказчик                   |
| Site      | Сайт               | Локация клиента                        |
| Check     | Проверка           | Мониторинговая проверка                |
| Alert     | Оповещение         | Не заменять на "тревога"               |
| Policy    | Политика           | Набор правил                           |
| Task      | Задача             | Плановое или ручное действие           |
| Script    | Скрипт             | В UI не заменять на "сценарий"         |
| Dashboard | Панель мониторинга | Допустимо: "Панель" при дефиците места |
| Service   | Служба             | Windows service                        |
| Event Log | Журнал событий     |                                        |
| Run       | Запустить          | Для действия/кнопки                    |
| Retry     | Повторить          |                                        |
| Success   | Успешно            | Статус выполнения                      |
| Failed    | Ошибка             | Для статуса/уведомления                |
| Pending   | В ожидании         |                                        |

## Не переводить

- `Tactical RMM`, названия продуктов и брендов.
- URL, API endpoint, JSON-ключи, имена переменных, команды терминала.
- Технические идентификаторы: `agent_id`, `site_id`, `SMTP`, `SSH`, `RDP`, `URL`, `DNS`.
