# Фаза 2. Нормализация ключей и словарей

## Статус

Фаза 2 выполнена: утверждена единая схема ключей и введена модульная структура словарей `en/ru`.

## Утвержденные namespaces

- `common`
- `auth`
- `dashboard`
- `navigation`
- `agents`
- `checks`
- `alerts`
- `scripts`
- `tasks`
- `software`
- `settings`
- `reporting`
- `errors`
- `notifications`

## Формат именования ключей

- Шаблон: `domain.section.action`
- Примеры:
  - `common.buttons.save`
  - `common.actions.retry`
  - `auth.form.submit`
  - `agents.dialog.deleteConfirm`

## Принятые правила

- Ключи именуются по смыслу, не по исходной английской строке.
- Новые ключи добавляются только в соответствующий namespace-файл.
- Для каждой новой строки поддерживается паритет ключей между `en` и `ru`.
- Плейсхолдеры и pluralization синхронны между языками.

## Структура словарей

- `src/i18n/en/*.json`
- `src/i18n/ru/*.json`
- Сборка namespace-файлов в:
  - `src/i18n/en/index.ts`
  - `src/i18n/ru/index.ts`

## Глоссарий терминов

Канонический глоссарий зафиксирован в `docs/i18n/glossary.ru.md` и обязателен для новых переводов.

## Критерий завершения Фазы 2

- Схема namespaces и формат ключей закреплены.
- Словари `en/ru` разнесены по модульным JSON-файлам.
- Есть единый словарь терминов для использования в следующих фазах.
